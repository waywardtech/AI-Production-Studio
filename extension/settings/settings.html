One-time setup: your Google Cloud client ID

Google requires every app that uses Drive to have its own client ID, created under your Google account. It takes about five minutes, once.

  1. Open Google Cloud Console → New project. Name it anything, e.g. edge-studio.
  2. In that project, open APIs & Services → Library → Google Drive API and click Enable. That's the only API needed.
  3. Open OAuth consent screen.
    • If your Google account is a Google Workspace account (your own domain), choose Internal. No review, no expiry.
    • Otherwise choose External, leave it in Testing, and add your own address under Test users. Google may ask you to reconnect about once a week in this mode.
  4. Open Credentials → Create credentials → OAuth client ID → application type Web application. Under Authorized redirect URIs, add exactly:
    …

    This address is tied to this copy of the extension (ID …). If you load Edge Studio from a different folder, its ID and this address change, and the redirect URI in Google Cloud needs updating to match.

Edge Studio asks for two narrow permissions: access to only the files it creates (not the rest of your Drive), and a hidden app-data folder for its index. Neither is a “sensitive” scope, so no Google verification is needed.

What goes where in Drive

Edge Studio/
  Project/
    Prompts/        a Doc per saved prompt — edit the text under each [Heading]
    Replies/        a Doc per saved reply
    Productions/
      Production/   its generated shot list
        In-box/     a Doc per script or note
        Out-box/    a Doc per dailies report

Deleting something in Edge Studio moves its Doc to your Drive trash, so it can be restored. Asset references, block types, scenes and tags are kept in a small hidden index, which is how a second computer picks up exactly where this one left off.
