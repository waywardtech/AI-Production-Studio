    How Edge Studio works

    1. Open a chat — ChatGPT, Claude or Gemini — then Refresh above and tick it.
    2. Build a prompt: click a block below, write, then Insert it into the chat. Save keeps it in this project.
    3. Capture the answer on Replies. Scripts and scene lists go To studio, where they become shots.
    4. Keep it all in Google Docs — connect in ⚙ Settings.
